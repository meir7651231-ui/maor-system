## (ב) חקירה: "הלקוח בפלטפורמת-הענן עדיין לא רואה את ה-40 יום"
**מה נבדק בקוד (כל מסלול שיכול לכבות `supporters.segula`):**

| מסלול | ממצא |
|---|---|
| `featureOn` | חסר = פעיל; כבוי רק ב-`false` מפורש או מודול-אב כבוי |
| `effectiveConfigFor` (כרטיס-עובד) | מגביל **רק** `false` מפורש; מפתח חדש שלא בכרטיס ⇒ ירושה (פעיל) |
| פרופילי-תפקיד (`rolePresets`) | מסתירים **מודולים** בלבד, בתוך תקרת-הארגון |
| חבילות-ורטיקל (`COMMERCIAL_OFF`) | 8 דגלים — segula **לא** ביניהם |
| אשף-ההקמה / לוח-הבקרה | כותבים `false` רק בכיבוי-ידני של הדגל |
| `resolveOrgConfig` / `normalizeConfig` | מעתיקים `features` כמו-שהם |
| `platformOrgs` חי | חל רק על ארגון-פלטפורמה; השורש = קובץ סטטי |

⇒ **אין מסלול שמכבה את הדגל כברירת-מחדל.** נשארו שתי סיבות שאי-אפשר לאמת מהריפו (אין גישה לענן-הבעלים):
1. הדגל כובה **ידנית** בקונפיג-הארגון של הלקוח (לוח-הבקרה ← דגלים ← תורמים).
2. מכשיר-הלקוח על **בנייה ישנה** (PWA מותקנת; "גרסת-האתר" בהגדרות תגיד).

**מה נבנה כדי שהסיבה תיראה במקום להיות מנוחשת:**
- **כרטיס-תורם:** דגל כבוי ⇒ הודעה גלויה `🕯 "40 ימים" כבוי בהגדרות-הארגון הזה (דגל supporters.segula)` — לא העלמה שקטה.
- **הגדרות ← הארגון שלי ← "🔎 אבחון דגלים"** (ליד גרסת-האתר): `org · cloud/מייל/manager · build · supporters module · supporters.segula ON/OFF · raw · modules off · features off`. הלקוח מצלם, הבעלים רואה מיד.
- ratchets: `teachers-csv-segula-diag.test.ts` (6) · `e2e/teachers-csv-segula-diag-smoke.mjs` (10/10 — כולל קונפיג עם הדגל כבוי).
