# RUNBOOK · הגנת-מקור (anti-clone) — למנוע לקוח שגורר את המערכת ומקים משלו

**האמת הטכנית:** אתר-web = קוד-צד-לקוח שרץ בדפדפן ⇒ **תמיד ניתן-להורדה**. אי-אפשר
למנוע גרירת ה-frontend. אבל אפשר להפוך את הגרירה לחסרת-ערך (הערך בשרת) ולהוסיף
שכבות-הרתעה+זיהוי. **המנוף החזק ביותר הוא משפטי** (הסכם-רישוי + זכויות-יוצרים) —
נעשה עם עו"ד, מחוץ לקוד.

## מה נבנה בקוד (16.8, דורמנטי-כברירת-מחדל)

### 1. 🛡️ App Check — השכבה הטכנית האמיתית
`src/lib/appCheck.ts` — מחובר ב-`initCloud` (`lib/cloud.ts`). כשמוגדר
`firebase.appCheckKey` (מפתח-אתר reCAPTCHA v3), כל בקשה ל-Firestore נושאת טוקן-
attestation שמוכיח שהיא מהאפליקציה-הרשמית. **עותק-מגורר על דומיין אחר → אין לו
טוקן תקין → Firestore דוחה.** דורמנטי בלי מפתח (ביט-זהה להיום), מדולג ב-Playwright.

**הפעלה (פעולת-בעלים, ~15 דק'):**
1. קונסולת Firebase ← **App Check** ← Register app ← ספק **reCAPTCHA v3** ← קבל מפתח-אתר.
2. הזן את המפתח בקונפיג-הארגון (`firebase.appCheckKey`) — דרך אשף-ההרכבה/הקונסולה.
3. קונסולת Firebase ← App Check ← **Enforce** על Firestore (ואם יש — Storage/Functions).
   ⚠️ להפעיל Enforce **רק אחרי** שהמפתח כבר חי אצל כל הלקוחות (אחרת בקשות יידחו).
4. בדיקה: טען את האתר הרשמי → עובד; טען עותק על דומיין-בדיקה → Firestore דוחה.

### 2. 🏷️ שומר-מארח (origin guard) — הרתעה+זיהוי
`src/lib/originGuard.ts` (טהור) — כשמוגדר `config.allowedHosts` (רשימת-מארחים
רשמיים), טעינה ממארח לא-מוכר מדפיסה **אזהרת-זכויות בקונסולה**. לא-חוסם (frontend
ניתן-לעריכה) — שכבת-הרתעה שמרימה מדרגת-מאמץ ומשאירה עקבה. דורמנטי בלי הרשימה.
הפעלה: הוסף ל-config `"allowedHosts": ["yourdomain.com", "yourorg.github.io"]`.

### 3. 🔑 שער-רישוי קשור-שרת (עתידי — דורש Blaze/functions)
עיצוב: Cloud Function `validateLicense(slug)` שקוראת `licenses/{slug}` (אוסף-שרת,
Rules read:false) ומחזירה טוקן-חתום בתוקף; האפליקציה מגדרת פיצ'רי-ענן בטוקן. הערך:
השער חוסם **משאב-שרת**, לא `if` בלקוח (שאפשר למחוק). ממתין לפריסת-functions (Blaze).

## מה שכבר מגן (בלי פעולה)
- **Firestore Rules** — עותק-מגורר שמכוון ל-Firebase שלך נחסם (לא-חבר). red-team מוכיח (`npm run test:rules`).
- **`functions/`** — קוד-שרת, לא נשלח לדפדפן ⇒ לא-ניתן-לגרירה.
- **אין source-maps בפרודקשן** (Vite default) — הקוד ממוזער.

## סדר-עדיפויות מומלץ לבעלים
1. **הסכם-רישוי משפטי** (עו"ד) — המנוף החזק ביותר, עוצר עסקים אמיתיים.
2. **App Check + Enforce** — השכבה הטכנית שבאמת חוסמת עותק מה-backend שלך.
3. `allowedHosts` — הרתעה זולה.
4. שער-רישוי קשור-שרת — כשה-functions באוויר.
