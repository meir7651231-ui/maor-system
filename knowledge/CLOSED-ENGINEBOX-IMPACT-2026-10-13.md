## 2. ה-API
```ts
export interface ImpactCtx { db: Db; config: OrgConfig; nowMs: number; ask?: AskFn }   // ask = ה-ask של המרכזייה, מוזרק
export interface Impact { key: string; headline: string; count: number; examples: readonly string[]; days: number }
export function impactOf(linkKey: string, ctx: ImpactCtx, days?: number): Impact | null;  // ברירה 30, תקרה 366, זבל ⇒ 30, 0 ⇒ 1
export function impactsFor(linkKeys: readonly string[], ctx: ImpactCtx, days?: number): Impact[];  // רק מה שיש לו מה לומר, בסדר, בלי כפילויות
export const IMPACT_MEASURES: Readonly<Record<string, ImpactMeasure>>;  // לפי impactKey(needer, plug) = 'host.stay|times.shabbat'
export function impactKey(needer: string, plug: string): string;
export const IMPACT_DEFAULT_DAYS = 30, IMPACT_MAX_DAYS = 366;
```
שינויים מההצעה: נוסף `days` ל-`Impact` (לכותרת/תווית); `examples` הוא `readonly`. מדד = `(win, ctx, giver) => {count, text, examples} | null` —
מקבל עם שני נותנים באותו מחבר (`host.dash|day.summary` ← זמנים / לוח) מנותב לפי `giver`. **חיבור חדש = שורה אחת ב-`IMPACT_MEASURES`.**

**חלון:** `days` הימים שמסתיימים היום (כולל), "היום" = `isoAt(nowMs)` בשעון-ישראל (`ORG_TZ`). חשבון-ימים על תאריכים קלנדריים (לא ms) ⇒
מעבר שעון-קיץ לא מזיז גבולות. **null** כש: המפתח לא חיבור תקין · אין מדד · אחד הצדדים כבוי (אותם שערים של `catalogFor`: מודול + תת-דגל) ·
אין נתונים במקבל · המדד צריך את `ask` ואין/לא ענה (loading/off/error/זורק). **count = 0** כשיש נתונים אבל בחלון לא היה מה לשנות — המשפט אומר
את זה במפורש ("…ולכן החיבור עוד לא היה משנה דבר"). לעולם לא זורק (try/catch עוטף + `ask` שזורק נבלע).

## 4. החלטות (כנות קודם)
1. **"הושלמה" נספרת, "בוטלה" לא.** בזמנה ההזמנה שהושלמה כן הייתה בשהייה והכרטיס כן היה מוצג.
2. **מקום-פנוי מחושב מהנתונים, לא מ-`hosting.availability`.** היכולת עונה על *עכשיו*: הזמנה שהושלמה לא תופסת, וסטטוס-חסימה נוכחי חוסם.
   נכון לקו היום — שגוי לעבר (היה מנפח לילות פנויים). כאן הזמנה שהושלמה תופסת את לילותיה; סטטוס-חסימה (אין לו היסטוריה) לא נלקח בחשבון —
   סטייה מכוונת מההוראה "via ask"; ה-ask משמש לדוגמה אחת אמיתית: מה הקו היה אומר **הלילה**.
3. **מניינים ושורות-הלוח בלי `ask` ⇒ null.** אין דרך כנה לדעת מה הלוח היה מחזיר בלי הספק שלו (לא מייבאים את קוד פרנסה׳לע לארגז).
   ספק שלא ענה באמצע (loading) ⇒ null — לא חצי-ספירה.
4. **מניינים/בעלי-מקצוע = לפי הלוח/המדריך של היום** (אין היסטוריה למודעות). הכותרת אומרת את זה במפורש ("לפי המדריך היום").
5. **מספרי-חירום ⇒ null כשהמדריך כבוי:** השורה יושבת בתוך חלון "מצא בעל מקצוע" (`FindProDialog`), שלא נפתח בלי `parnasa.findPro`.
6. **תקציר-היום בלשונית-האישורים:** שורת-האירוח מופיעה גם ביום ריק ("הגעות היום: 0") — לכן נספרים רק ימים עם תוכן אמיתי.
   מחושב מהנתונים (`hosting.today` עונה רק על "היום", ו"בשהייה" שלו = סטטוס נוכחי).
7. **שני מדדי לוח-הבקרה ⇒ null בלי שום יחידה/הזמנה** — אין "מה היה קורה" בלוח שאף אחד לא פותח.
8. **"קריאה שטופלה"** נספרת רק כש-`hosting.maint` דלוק — כמו `hostToday`.

לתקציר). מקום-פנוי: O(הזמנות × לילות-בחלון) + O(לילות × יחידות × חדרים). נמדד: **כל 11 המדדים על 5,000 הזמנות + 2,000 קריאות, עם ובלי

## 6. איך המשלב מציג את זה על המסך
בכל אפשרות-חיבור של `connectOptions(...)` (ה-`key` שלה הוא מפתח-החיבור):
```ts
import { impactOf } from '../lib/enginebox/impact';          // ⇒ impact/index.ts
import { ask } from '../lib/switchboard/registry';
// ctx — מאותו מקום של useSwitchCtx: { db, config, nowMs } + ask. לפני כן: loadProviders(config) (עצל, אידמפוטנטי).
const im = impactOf(opt.key, { db, config, nowMs, ask });
```
- **מתחת לשורת "התוצאה תהיה…" (`opt.result`)** — תיבה קטנה "🔍 ב-30 הימים האחרונים אצלכם": `im.headline` בשורה אחת, ומתחתיה עד 3
  `im.examples` באפור (רשימה). **`im === null` ⇒ לא מציגים את התיבה בכלל** (לא "אין נתונים", לא 0 מומצא).
- **`im.count === 0`** ⇒ מציגים את הכותרת כמו שהיא (היא כבר אומרת "…עוד לא היה משנה דבר") בצבע ניטרלי — זה מידע כן, לא מכירה.
- **אפשרות שכבר מחוברת (`linked`)** — אותה תיבה בכותרת "מה החיבור עשה אצלכם" (הניסוח "היה מקבל" נשאר נכון גם כשהיה מחובר — המדד סופר
  את מה שהקוד עשה/היה עושה).
- **הספק עוד נטען** — מדדים 3/4/9/10 מחזירים null עד ש-`loadProviders` מסתיים; רנדור מחדש דרך `subscribeSwitchboard`/`switchboardVersion`
  (אותו מנגנון של כרטיס-התקציר) יציג אותם כשיגיעו.
- **בחירת חלון** (אופציונלי) — צ׳יפים 7/30/90 יום ⇒ `impactOf(key, ctx, days)`; הכותרת מתעדכנת ("ב-7 הימים האחרונים…").
- **רשימה** (מסך "מה מחובר אצלי") — `impactsFor(effectiveLinks(stored), ctx)` ⇒ כרטיס לכל חיבור שיש לו מה לומר.
- **ייצוא ב-barrel:** שורה אחת ב-`src/lib/enginebox/index.ts`: `export * from './impact';` — שימו לב: זה גורר את `config` ואת עזרי-האירוח
  (`transitions`/`switchLinks`) לכל מי שמייבא את ה-barrel; הבנדל-הראשי מייבא רק `links`/`linkShape` ולכן לא מושפע.
