## 🧩 מכונת-השילוב (`combine.mjs`)

| | |
|---|---|
| מועמדים | קודם רמזי `verb-recipes.json` (פועל/סוג לכל שלב), ואז ליבה מוכחת ל-V + מתאם-סוג מוכח (`adapterRole`). עד 24 לזוג (פועל·חומר), דטרמיניסטי |
| צורות | `chain` — P2(P1(a…), b…) · `pair` — P2(P1(x…), P1(y…)) (לפועל דו-מקומי; `at` = הקלט של P1 שמשחק את "הדבר") |

| **תצוגה** | השילוב נפרש לכל החלקים (כל אחד פעם אחת, עם "נמצא ב:" / "נמצא בתוך:") + "N חלקים · עבר N/N חוקים של <פועל>" |

**כיוון השמש** (`combo-sun-heading-number.json`, 72/72): חצות-היום (ליבת מקום-השמש) ⇒ דקות-מחצות (הפרש של גלגל-החוגים) ⇒ נטיית-השמש (זמני-היום של פרנס׳לע) ⇒ נקודה-על-מעגל ×3 (ליבת המקיף, מהגלקסיה/היקום-3D) ⇒ רבע-סיבוב והטיה לפי קו-הרוחב (`project` של היקום-3D) ⇒ אורך על האופק ×2 (מרחק-המצביע של המטבע) ⇒ יחס (מחלק) ⇒ זווית-מיחס (arccos של זמני-הזריחה) ⇒ חצי+חצי (מחבר של זמני-הזריחה). הטריק: אזימוט = 2·arccos(מזרח / |(צפון − אורך, מזרח)|) — חצי-זווית, בלי atan2 (אין חלק atan2 מוכח בקטלוג).

## 🧭 MACHINE-V3 — צורת `on`, מתאמי-צורה, טבעת 1 בלי תקרה (14.10.2026)

| | |
|---|---|
| **`on`** — אותו חלק, על החומר | חלק מוכח ל-V שהקלט שלו פתוח **בקוד** (`any` · `T` · `T[]` · `Array<T>`…). במקום הקלט הזה נכנס החומר עצמו (`MATERIAL_DESC`: נקודות `{x,y}` · צלילים `{f,t,d,g}` · תמונות `{src: data:image/…, width, height}` · תור `{id, status}`), ומקבלים רק אם החוקים של V עוברים n/n **והקישור שעבר הוא הקלט שהוחלף**. רק לארבעת הסוגים. סדר: רמזים ⇒ `on` ⇒ ליבה+מתאם ⇒ עומק 3 |
| **מתאם-צורה** (`shapeAdapter`) | מתאם-סוג מוכח שהקלט הראשי או הפלט שלו מקום/קול/תמונה/תור, והקלטים הנוספים **מספרים בלבד** (זווית, קנה-מידה). למשל `project(p, yaw, pitch)` של היקום-3D |
| **על החומר** | בשרשרת/זוג על אחד מארבעת הסוגים — החוקים חייבים לעבור על הקלט הראשון (בזוג: שני העותקים), לא על פרמטר צדדי |
| **רמז `{part}`** | שלב ברמז יכול לנקוב בחלק בשמו המלא (+`verb` = התפקיד שהוא מוכח לו). משמש את הדרקון: מודד-המרחק של הגלקסיה |
| **טבעת 1 בלי `CAP_CORE`** | חלק בודד: כל החלקים שמוכחים לפועל, בסדר הדירוג של האינדקס. טבעות 2–3 נשארות על 60 הראשונים |
| **`fitPart`** | תור ⊂ רשימה, מנגינה ⊂ רצף — רק בצד החלק |
| **`lawMat`** | גם `record:<x>` לפועל שמקבל/נותן "רשומה" (לא מפרט של פועל-תנועה) |
