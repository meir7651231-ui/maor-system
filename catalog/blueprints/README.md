# 🧭 מנוע-השרטוטים · Blueprints

**לבעלים, בשלוש שורות:** "שרטוט" = צורת-חיבור בלי חלקים ("בנה מהר ואז שפר עד שאין שיפור", "מיין ואז קח ראשון"…).
המנוע לוקח פועל עם חוקים, מוצא שרטוטים שמתאימים לחתימה שלו, ממלא את המשבצות בחלקים מוכחים, ומקבל רק מה שעובר
את כל חוקי הפועל — בשלושה זרעים ובקלטי-לחץ. **המבחן הכן** (מה הוא מגלה לבד ומה לא): `knowledge/CLOSED-BLUEPRINTS-2026-10-14.md`.

```bash
node catalog/inner/lib/ensure-gen.mjs          # (פעם אחת בשכפול טרי — המודולים הפנימיים)
node catalog/blueprints/mine.mjs               # כורה-השרטוטים ⇒ library.json      (--check)
node catalog/blueprints/search.mjs             # החיפוש העיוור ⇒ ledger.json + found/ (--check · --only <פועל>)
node catalog/blueprints/truth.mjs              # בדיקת-אמת בדיעבד ⇒ truth.json      (--check)
npx vitest run catalog/__tests__/blueprints.test.ts
```

| קובץ | מה |
|---|---|
| `mine.mjs` | כורה: TS AST (בלי להריץ) על אורביט + הליבות + החלקים המורמים של 6 הריפואים החיצוניים ⇒ צורת-חיבור לכל פונקציה (לולאה · חזרה-עד-שאין-שינוי · צבירה · מיפוי · סינון · מיין-ואז-ראשון · קבץ-ואז-ספור · בחירה-לפי-תנאי · חיפוש-בינארי · תור · חלון · מיזוג), קריאות ⇒ משבצות-פועל. נרמול + דדופ ⇒ `library.json` |
| `shapes.mjs` | 25 צורות-על (22 ברות-הרצה), כל אחת תבנית בפורמט של `combiner/graph.mjs` עם משבצות במקום חלקים + חוזה-משבצת כללי + "נמצא ב:" מהכרייה. **אין בה מזהה-חלק** |
| `engine.mjs` | התאמת-חתימה · מאגר-משבצת (סוג מדויק קודם, סבב בין פעלים, בלי חלקים של פועל-היעד) · סינון-משבצת בהרצה (סוג + חוזה + תאומי-התנהגות) · פריסת-ארגומנטים (נקודה ⇒ x,y) · מילוי "הטוב-קודם" · הרחבה לגרף |
| `search.mjs` | החיפוש: לכל פועל ב-`targets.json` — כל התבניות המתאימות, עד התקציב; אימות = `composeGraph` + `verify` של מכונת-השילוב (חוקי פועל-היעד בלבד) ב-3 זרעים + קלטי-לחץ; דירוג: פחות חלקים ⇒ פחות צעדים ⇒ מזהה. **שומר-קריאה** חוסם את המתכונים המוסתרים |
| `truth.mjs` | **לא חלק מהחיפוש:** האם מה שעבר את החוקים עושה את מה שהפועל *אומר*? (כפולים, קלטים גדולים, שליליים; איכות מול הייחוס) |
| `run.mjs` | שילוב מהמדף ⇒ פונקציה רגילה (כל צומת רץ בארגז-החול מהקוד המקורי) |
| `found/` | המדף: כל שילוב שעבר, בפורמט של `catalog/recipes/combo-*.json` + `by: "מנוע-השרטוטים"` + החלופות שעברו |
| `ledger.json` | הפנקס: לכל פועל — מה הוסתר, אילו תבניות נוסו, גודל-המרחב, כמה ניסיונות, כמה עברו, מה נכשל ולמה |

המדף **לא** נכנס ל-`catalog/recipes/` במכוון: שם הוא היה משנה את הקלטים של `combine`/`build`/`bundle` (והחותמות שלהם).
