"הוא מתחיל לבנות: חיבור א עם ב — יצא ג. הוא רושם ג. הוא הולך ומחפש: יש ג יותר טוב או לא? אם אין — הוא רושם אותו.
אם יש — הוא בודק איזה מהם יותר טוב, וממשיך לבנות מעליו." (הבעלים, 15.10.2026)

בלי בקשה ובלי מטרה. **GROW3:** תשואה לעוגן ולשותף (כפולים ⇒ יורד), לא-בונים-פעמיים-אותן-טביעות, עוגנים לפי פועל בגלים, שומר-כפולים, סולם בלי עטיפות, מדד "נבנה מחדש בדיוק" — `knowledge/CLOSED-GROW3-2026-10-15.md`. **GROW2:** ניקוד-תועלת (קרבה לפעלים), בחירה לפי ניקוד, זבל לפני המדף, בדיקת-לחץ — `knowledge/CLOSED-GROW2-2026-10-15.md`. דטרמיניסטי, בלי AI, בלי שעון בפנקס. הדוח: `knowledge/CLOSED-GROW-2026-10-15.md`.

| קובץ | מה |
|---|---|
| `lib.mjs` | טהור: העולם (4 סוגים: מספר · רשימת-מספרים · נקודה · רשימת-נקודות, עד 2 קלטים) · סט-הקלטים הקבוע (כולל לחץ) · טביעה וזבל · צורות-החיבור כגרף של `combiner/graph.mjs` (chain · pair · map · mapc · fold · fix) + הטמעה · דגימת-זוגות בלי לפרוס |
| `truth.mjs` | בדיקת-אמת: שם של sum/average/extreme (חוקים חלשים) רק אם עבר גם אותה |
| `grow.mjs` | הריצה: קומה 0 ⇒ קומות ⇒ מתאר (חוקי כל הפעלים) ⇒ גילויים (מול מימושי-הייחוס) ⇒ `ledger.json` + `shelf/` |
| `runtime.mjs` | GROW2: ארגז-החול — טוען חלקים ומריץ דבר (גרף) על קלט; משותף לבדיקה |
| `compare.json` | GROW2/3: שתי ריצות באותו תקציב — random (הישן) מול score (לפי ניקוד) — והמדדים |
| `fixtures/wrong-improvements.json` | GROW2: שני השיפורים השגויים של GROW (בדיקת-שימור: נדחים בלחץ) |
| `budget.json` | התקציב המוצהר |
| `ledger.json` | הפנקס: לכל קומה נבנו/חדשים/הוחלפו/כפולים/זבל/קיבלו-שם, שיפורים, גילויים |
| `shelf/floor-0.json` | קומה 0 — רשומות מלאות |
| `shelf/floor-N.json` | קומות 1+ — שורה לכל דבר: `[id, צורה, ממה, חתימה, צעדים, צמתים, פעלים, טביעה]` |
| `shelf/named.json` · `improved.json` | רשומות מלאות (ממה, מה עושה, החלקים, דוגמה) לבעלי-שם-מיוחד ולשיפורים |
| `shelf/replaced.json` | מה שהוחלף בדרך ועדיין בשרשרת של משהו שנשאר |
| `shelf/parts.json` | לכל חלק-בסיס: "נמצא ב:" |
