# 📇 קטלוג החלקים · Parts Catalog

**לבעלים, בשלוש שורות:**
1. כל מה שבנינו מפורק כאן לחלקים קטנים, וכל חלק כתוב באותה צורה: מה הוא עושה (בעברית פשוטה), מה הוא מקבל ומה הוא נותן.
2. בגלל שכולם כתובים באותה שפה, מכונה אחת תוכל לחפש צירופים של חלקים מכל הפרויקטים יחד — ולבנות מהם דבר חדש.
3. כאן נמצא החוזה (איך כותבים חלק), ואורביט כבר בפנים: **979 חלקים**. שאר הפרויקטים מצטרפים לאותה תיקייה.

- החוזה: [`contract.md`](./contract.md) · הסכמה: [`schema.json`](./schema.json) · הבודק: [`lib/check.mjs`](./lib/check.mjs)
- המקורות: `sources/<source>.json` — אורביט: [`sources/orbit.json`](./sources/orbit.json). את `generator`, `rings`, `buildsmart`, `yeshiva`, `qa-scanner`, `yoman-habina`, `14kk`, `mmmm` כותבים סשנים אחרים.
- התיקייה לא נכנסת לאפליקציה (אין ייבוא מ-`src/`), והיא לא משנה שום דבר באתר החי.

```bash
node catalog/scripts/orbit-census.mjs           # כותב את sources/orbit.json
node catalog/scripts/orbit-census.mjs --check   # יציאה 1 אם לא מעודכן או לא עומד בחוזה

```

**מתי צריך:** שינוי בקובץ טהור של מודול, ב-`src/lib` שברשימה, בחלקים הקטנים, בכרטיסים או בספריות הטלפון ⇒ קודם `npm run atoms:factory` (אם המפרק הושפע), ואז המפקד, וקומיט של `sources/orbit.json`. הבדיקה ב-`npm test` נכשלת אם שכחו.

### איך המפקד עובד

1. **המפרק** — קורא את `src/lib/atoms/engines/generated/*.ts` (בלי להריץ) ⇒ 17 `engine` + 733 `function`.
2. **החלקים הקטנים** — `src/lib/atoms/parts/*.ts`; השם וההסבר של ה-`brick` מ-`explain.ts` (הטקסטים שאושרו).
3. **כרטיסי-היד** — `src/lib/atoms/engines/{zmanim,whatNeed,bookings}.ts` ⇒ `engine` + `particle` (הסוגים של כל particle נקבעו ביד בתוך הסקריפט, `PARTICLE_KINDS`).
4. **`src/lib`** — רשימה גלויה (`LIB_FILES`) של קבצים שימושיים; נכנס רק קובץ שעובר את בדיקת-הטוהר של המפרק.
5. **הטלפון** — `telephony/lib/*.mjs` (`TEL_FILES`: זמנים, לוח עברי, ניתוב-תפריט, נרמול, תזכורות, סימולטור…).
- החתימות: דרך ה-API של המהדר `typescript` (טיפוס-חזרה שלא נכתב — מוסק).
- הסוגים: `kindOf` — טיפוס + שם ⇒ אחד מסוגי המילון. עדיף `unknown` אמיתי על ניחוש.
- השמות: מההערה העברית בקוד ⇒ צורת-פועל (`verbify`) ⇒ דריסה ביד ב-[`names/orbit.json`](./names/orbit.json) (~200 שמות). כלל: פועל בהווה, עד 9 מילים, בלי לטינית.
- הדוגמאות: `expect(f(…)).toBe(…)` / `eq(…, f(…), …)` מילוליים בלבד, מבדיקה שמייבאת את הקובץ של החלק, ואחרי מסנן-הפרטיות של החוזה §4.
- דטרמיניסטי: אותו קוד ⇒ אותו קובץ; `generatedAt: null`; `ref` נכתב בהרצה ולא נבדק ב-`--check`.
