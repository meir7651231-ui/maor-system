# 📗 מדריך-המפעיל — מרכזייה מתצורה-עצמית

> אתה מפעיל את המרכזייה מרכזית לכל הלקוחות. הוספת-לקוח = מילוי-נתונים.
> **pure-downstream:** אתה אחרי כל הספקים, מדבר רק עם הלקוח.

## הזרימה (מקצה-לקצה)

1. **קליטת-לקוח** — ממלאים את נתוני-הלקוח (אשף / CSV / ידני) → קובץ `<tenant>.json`.
2. **תקינות** — `node telephony/tel.mjs validate <tenant>.json` → ✅/שגיאות.
3. **תצוגה-מקדימה** — `node telephony/tel.mjs preview <tenant>.json` → איך שיחות ינותבו + מוכנות.
4. **החלה** — `node telephony/tel.mjs apply <tenantsDir> <configRoot> --write` → כותב לספריית-המרכזייה.
5. **טעינה** — ב-FreeSWITCH: `fs_cli -x reloadxml` (+`sofia profile internal rescan` אם השתנו gateways).
6. **בדיקה** — מתקשרים לכל מספר בשעות ואחרי; מחייגים החוצה עם קידומת.

## מה ממלאים ללקוח (מינימום)

| שדה | דוגמה | הערה |
|---|---|---|
| tenantId | `chesed-tel` | slug אנגלי = domain |
| orgName | מאור החסד | |
| vertical | chesed/kollel/gemach/… | זורע ברירות (שעות/לוח-עברי) |
| numbers[] | מספר · כינוי · סוג | סוג נגזר אוטומטית מהקידומת |
| officeHours | ימים · מ־ · עד | (או מהוורטיקל) |
| destinations | שלוחת-משרד · שלוחת-מנהל · מייל-תא-קולי | |

**סוגי-מספר (נגזר אוטומטית):** `05x`→SIM-בשער · `07x`→וירטואלי (הלקוח מפנה אליך) ·
ווצאפ→קישור-מכשיר. אתה לא נרשם לאף ספק.

## פיצ׳רים אופציונליים (דגלים — חסר=כבוי, ביט-זהה)

| דגל | מה נותן |
|---|---|
| `calendar.hebrew` | חג-עברי → סגור (מחושב-מראש) |
| `voice.ivr` | תפריט "הקש 1…" |
| `voice.queue` | תור-שיחות (סוכן מקבל ב-`*20`) |
| `voice.greeting` | ברכות פתוח/סגור/חג (הקלטות ב-`manifest.requiredPrompts`) |
| `voice.blocklist` | חסימת-מספרים |
| `recording` | הקלטת-שיחות |
| `emergency` | מתג "סגור היום" |

## חיוג-החוצה

המנהל מקיש `<ערוץ>#<מספר>` → יוצא דרך SIM-הערוץ (הצד-השני רואה את המספר הזה).
חיוג-רגיל בלי-קידומת → יוצא דרך מספר-ברירת-המחדל.

## חיבור-מאור (CTI)

`cti.mode: directory` → מאור כותב `directory/<e164>` (opt-in, מגודר-דגל); המרכזייה
קוראת מפתח-מינימלי ⇒ שיחה ממספר-מוכר קופצת לכרטיס Family/Supporter. **קריאה-בלבד.**

## תפעול שוטף

- **גיבוי/שחזור:** `snapshot`/`restoreFrom` — כל החלה נשמרת עם version.
- **סחף:** `detectDrift` — מזהה עריכה-ידנית מחוץ-למנוע.
- **בריאות:** `healthReport` — registration/latency פר-gateway/שלוחה.
- **חיוב:** `meterUsage` (מ-CDR) → `computeInvoice` (PLANS: בסיסי/רגיל/מורחב).
- **תאימות:** `complianceReport` — הצפנה/פרטיות/fail-safe/בידוד פר-לקוח.

## פתרון-תקלות מהיר

| תופעה | בדיקה |
