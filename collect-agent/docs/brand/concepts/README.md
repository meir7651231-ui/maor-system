# גבי — סבב קונספטים ללוגו (טיוטה לבחירה)

> הנקודה שממנה התחלתי היא הסיפור, «**הכסף שלך חוזר. בלי שתצטרך לרדוף.**», ולא האות ג׳.
> **לא הוחל על המוצר.** הלוגו הזמני (ג) נשאר ב-`web/src/brand/logo.ts` עד להכרעה. אחרי שתבחרו, מעבירים את הכיוון שנבחר לשם ומריצים `npm run logo`.

**קבצים:**
- `board.png`: לוח השוואה. כל כיוון בגדלים 512/64/24, על רקע בהיר וכהה, וגם בשילוב עם השם. בלוח, גודל 512 מוצג מוקטן ל-160.
- `actual-24px.png`: כל הכיוונים ב-24 פיקסלים אמיתיים, בלי הגדלה, כמו פאביקון.
- `<id>-light.svg` / `<id>-dark.svg`: קובצי 512.
- `board.html`: לוח אינטראקטיבי.

**מקור יחיד:** `web/scripts/concepts.mjs`. כדי לייצר מחדש: `NODE_PATH=$(npm root -g) node web/scripts/concepts-board.mjs`.
**פלטה:** ירוק `#10B981` (התנועה והכסף), נייבי `#0F172A` (הפרט המוביל), קרם `#FBF8F1`. על רקע כהה הנייבי מתחלף לקרם, ולכן אין צורך באריח.

**ההמלצה שלי:**
1. **בומרנג (1).** הוא היחיד שמספר את כל הסיפור, גם "חוזר" וגם "בלי לרדוף", בלי להיות אייקון מערכת גנרי.
2. **כף יד (2)** כחלופה חמה, אם רוצים להדגיש את הרוגע של בעל העסק.
3. **לא מומלצים:** 3 ו-5 בגלל שהם גנריים, ו-4 בגלל קונוטציית המניפולציה מול חייבים.

**השלב הבא, אחרי בחירה:** 2–3 ליטושים לכיוון שנבחר (משקל קו, זווית, יחס סמל-שם), בדיקת מונוכרום (חותמת, פקס, הדפסה), ואז החלפה ב-`brand/logo.ts`. הבדיקות הקיימות (עין/פרט נייבי, קבצים ציבוריים מסונכרנים, אריח על רקע כהה) יותאמו לסמל החדש.
