## חיוב דרך אורביט (הכרעת מאיר, 8.11.2026)

**עסקים משלמים על גבי דרך אורביט.** אורביט מחייב; לגבי אין מנגנון חיוב משלו. המחיר לא משתנה: ₪119 לחודש או ₪1,190 לשנה, 14 ימי ניסיון, בלי כרטיס אשראי.

| | |
|---|---|
| **איפה המנוי** | באורביט, פר-ארגון (`platformOrgs/{slug}.billing.gabi`): מסלול חודשי/שנתי, מצב (ניסיון/פעיל/באיחור/בוטל), תחילת ניסיון, «שולם עד». רק מנהל-המערכת של אורביט מעדכן. |
| **איך משלמים** | קישור לעמוד-התשלום של אורביט, מתוך הגדרות ← גבי באורביט. אין טיפול בכרטיס בקוד, ואין חיוב אוטומטי. |
| **איך גבי יודע** | בכל «התחברות לגבי» מאורביט נמסרת **זכאות חתומה וקצרת-מועד** (מפתח שקיים רק בשרתים, לא אצל הלקוח). גבי שומר את האחרונה (עם זמן קבלה) ומחליט לפיה. |
| **ניסיון** | 14 יום מתאריך תחילת הניסיון שאורביט קבע. 3 ימים לפני הסוף: הודעה לבעל העסק עם קישור לאורביט. בסוף: התזכורות נעצרות. |
| **פעיל** | שולח עד «שולם עד» כולל. |
| **תשלום באיחור / לא חודש** | **7 ימי חסד** מ«שולם עד»: התזכורות ממשיכות, ובעל העסק מקבל הודעה עם המועד והקישור. אחר-כך עצירה. |
| **בוטל** | עצירה מיידית, בלי חסד. |
| **«עצירה»** | גבי לא מתכנן ולא שולח תזכורות חדשות (גם תשובות בתור ממתינות). הנתונים נשמרים. בעל העסק רואה הודעה בעברית עם קישור לחיוב באורביט. |
| **עסק שלא מקושר לאורביט** | בדיוק כמו היום (`TRIAL_START` של הפריסה). |

- למה 7 ימים ולמה בוטל = מיידי: שמרני לשני הצדדים. החסד מכסה עיכוב רישום או רענון באורביט כדי שחייבים לא יפסיקו לקבל תזכורת באמצע סולם. ביטול הוא בחירה מפורשת של העסק, ולכן אין סיבה להמשיך לשלוח בשמו.
- מצב: **דורמנטי.** ההרחבה `gabi` באורביט עדיין «בפיתוח» (לא נמכרת). חוזה מלא: `knowledge/BUILD-ORDER-GABI-STORE-2026-11-07.md` §7.
