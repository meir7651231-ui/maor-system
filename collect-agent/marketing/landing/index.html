שאלות נפוצות

עם אילו מערכות חשבוניות גבי עובד?

חשבונית ירוקה (morning), iCount ורווחית; EZcount בבדיקה מול הספק. בכולן גבי מתחבר דרך מפתח API שאתה יוצר בחשבון שלך. אין API? אפשר לייבא קובץ CSV. עם API הרשימה מתעדכנת לבד כל בוקר; עם CSV היא נבנית מהקובץ האחרון שהעלית, וגבי מזכיר לך להעלות חדש כשהוא בן יותר מיום.

גבי יכול לשנות משהו בחשבונות שלי?

לא. גבי רק קורא חשבוניות פתוחות. הוא לא יוצר, לא עורך ולא מוחק מסמכים.

בשם מי יוצאת ההודעה?

בשם העסק שלך. הלקוח רואה את שם העסק.

מה אם הלקוח כבר שילם?

כשהחשבונית נסגרת במערכת החשבוניות שלך, התזכורות נעצרות. אם הלקוח כותב «שילמתי», גבי עוצר ושואל אותך.

כמה תזכורות לקוח יקבל?

לכל היותר 3 לכל חשבונית. אחר כך גבי עוצר ומעדכן אותך, וההחלטה מה לעשות אצלך.

זה מכתב התראה משפטי?

לא. אלה תזכורות עובדתיות על החשבוניות שלך. אם שוקלים הליך משפטי, כדאי להתייעץ עם עו״ד.
