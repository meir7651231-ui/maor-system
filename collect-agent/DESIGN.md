## 4. כללי תוכן (נאכפים בבדיקות, בשני הצדדים)
- **מקור האמת לנוסחים = `app/templates.py`** (סשן הבקאנד). `web/src/lib/message.ts` הוא מראה אות-באות, ובדיקה `tests/lib.check.ts` קוראת את `templates.py` ונכשלת על כל סטייה (נבדק במוטציה). שינוי נוסח: קודם בבקאנד, אחר כך כאן.
- כל SMS: מתחיל ב-`{שם העסק}:` (זיהוי השולח), **קישור תשלום**, **קישור הסרה** (`/u/{token}`). כל מייל: קישור+כפתור תשלום, `List-Unsubscribe`.
- ⚖️ חוק התקשורת §30א: תזכורת על חשבונית של לקוח קיים = הודעה שירותית, **רק אם נקייה משיווק** ⇒ אין מבצע/הנחה/הטבה/קופון וגם אין איומים (`MARKETING_WORDS`/`THREAT_WORDS` בבקאנד; אותה רשימה בבדיקת הממשק). פירוט: `docs/MVP-SPEC.md §4א`, `docs/CHANNELS-RESEARCH.md`.
- SMS בעברית: 70/67 תווים למקטע — הנוסחים כ-3 מקטעים; המונה בממשק מזהיר מעל 3 ואם נמחק קישור התשלום.
- חלון שליחה: א׳–ה׳ 9–19, ו׳ 9–12, לא שבת/חג (מראה של `app/policy.py` ב-`web/src/lib/policy.ts`). אין בחוק מגבלת שעות ל-SMS שירותי — זו מדיניות נגד הטרדה.
- "תזכורת אחרונה" והודעה ראשונה ללקוח — תמיד באישור הבעלים.

## 5. חוזה מול הבקאנד
| ממשק (`web/src/lib`) | בקאנד (`app/`) |
|---|---|
| `Step` friendly/second/plan_offer/final | `templates.STEPS[].key` |
| `TEMPLATES` / `buildSms` / `buildEmail` | `templates.STEPS` + `render_sms` / `render_email` (מראה, בדיקת סנכרון) |
| `fmtAmountBackend` → "12,870 ₪" | `templates.fmt_amount` |
| `demoUnsubUrl` | `service.unsub_url` → `{PUBLIC_BASE_URL}/u/{token}` |
| `Invoice.payUrl` | `paylinks.py` — דף תשלום של חשבונית ירוקה ⇒ קישור קבוע ⇒ חסימה |
| `canSendAt/nextAllowed` | `policy.Policy` |
| `Business.smsProvider/smsSender` | `Settings.sms_provider` (ברירת מחדל 019) / שם שולח |
| `approveAndSend` | אישור תזכורת → dispatch (dry-run) |
סכומים בממשק ב-₪ שלמים; בבקאנד באגורות. הבקאנד מגיש גם ממשק-תפעול רזה ב-`/ui` (`app/ui.html`); `web/` הוא המוצר המעוצב (נחיתה+הרשמה+דשבורד) ויחליף אותו כשיחובר ל-API.
**הצעה לבקאנד:** כפתור התשלום במייל (`render_email`) צבוע `#0f766e` — להחליף ל-`#10B981` עם טקסט `#0F172A` (מותג + ניגודיות).

## 6. הרצה ובדיקה
```bash
cd collect-agent/web && npm ci
npm run dev          # http://localhost:5173
npm test             # 7 בדיקות (node:test) — פורמט, נוסחים, מקטעים, סולם, מדיניות שעות, סטטיסטיקה, סנכרון מול templates.py
npm run build        # typecheck + build
node e2e/shots.mjs <dir>   # Playwright: כל המסכים + אשר-ושלח + חיפוש + מובייל 390px, 0 שגיאות קונסולה
```
