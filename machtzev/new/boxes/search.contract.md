# חוזה · קופסת-חיבורים "חיפוש"
**תפקיד:** חיפוש-חכם מלא: נרמול עברי + תעתיקים (עברית/אנגלית/רוסית/כינויים) +
סובלנות שגיאות-כתיב + ריבוי-מילים (AND) + סינון-ומיון יציב.
**חיווט (כל התלות כאן, לא בחוטים):**
norm-search ← xlat ← score-term(norm, levenshtein) ← smart-score(norm, expand, score) ← smart-filter.
**חשיפה:** ‏search(q, items, getTerms, limit?) · ‏score(q, terms) · ‏expand(q).
**דוגמאות מחייבות (קצה-לקצה):** חיפוש "cohen" מוצא את "משפחת כהן" · "חוגים"
מוצא "חוג" · "דוד כהן" ממיין התאמה-כפולה ראשונה · "xyz" מחזיר ריק · ריקה מחזירה הכול.
**הבטחה:** ניתוק כל חוט מהקופסה לא נוגע באף חוט אחר.
