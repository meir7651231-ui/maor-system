# חוזה · קופסת-ערכה
**תפקיד:** מחווטת תפקידים (שקעים: ‎--bg, ‎--ink…) לפיגמנטים מהפלטה, פר-מצב
(אור/לילה = שתי תוכניות-חיווט של אותם אטומים), ופולטת CSS מלא.
**חשיפה:** ‏cssFor(mode, overrides?) — ‏overrides הוא כפתור-הצבע: החלפת פיגמנט
אחת מתעדכנת בכל תפקיד שמחווט אליו.
**התחייבויות (הבדיקה מוכיחה):** כל שקע מחווט לפיגמנט קיים (אחרת חריגה) ·
‏82 תפקידים בכל מצב · שינוי-פיגמנט-אחד משנה את כל מופעיו ואפס אחרים ·
מצב לא-מוכר ⇒ חריגה ברורה.
**קירוב v1 (מוצהר):** אור=ערך-ראשון, חושך=ערך-אחרון; הקשר-סלקטור מלא — בגל הבא.
