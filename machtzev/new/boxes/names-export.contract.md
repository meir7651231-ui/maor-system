# חוזה · קופסת-חיבורים "כפתור ייצוא-השמות"
**תפקיד:** הקופסה של הכפתור מהדוגמה — "⬇ ייצוא CSV" ממסך מעקב-הטיפול.
כל מה שהיה מולחם ב-3 קבצים — מחווט כאן במקום אחד:
תווית ← מילון · הרשאה ← is-admin · תוכן ← to-csv(csv-escape) · שם-קובץ.
**חשיפה:** ‏exportNames({ rows, userEmail, adminEmails }) ⇒
‏{ allowed:false } או { allowed:true, filename, content (CSV מוגן+BOM), label }.
ההורדה עצמה (DOM) היא שקע של לוח-האם — הקופסה טהורה.
**דוגמאות מחייבות:** מנהל מקבל קובץ עם BOM והזרקה-חסומה · לא-מנהל ⇒ allowed:false
בלי תוכן · רשימת-מנהלים ריקה ⇒ מותר (מצב-מקומי) · תא "=HACK" יוצא "'=HACK".
