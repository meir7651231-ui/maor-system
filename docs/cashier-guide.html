1. בבוקר

  1. מוודאים שהכרטיס בתוך הקופה, ומדליקים.
  2. מסתכלים על התאריך והשעה בראש המסך. לא נכון? ראו "כיוון שעון".
  3. כתוב "צריך לסגור את היום הקודם"? עושים סגירת יום (סעיף 6) ואז מוכרים.

2. מכירה

  1. סורקים כל מוצר באקדח. אותו מוצר פעמיים = כמות 2.
  2. כמות: מקלידים מספר ← × כמות (על השורה האחרונה, או זו שנבחרה ב-▲▼).
  3. אין ברקוד? מקלידים את המספר שמתחת לפסים ← אישור.
  4. מוצר בלי ברקוד / מחיר חופשי: מקלידים מחיר ← מחיר.
  5. טעות בשורה: בוחרים ב-▲▼ ← מחק.
  6. C מוחק רק את מה שהוקלד עכשיו.

3. תשלום במזומן

  1. מזומן
  2. מקלידים כמה הלקוח נתן (למשל 200) ← אישור.
  3. המסך מראה את העודף, המגירה נפתחת, הקבלה יוצאת.
  4. נתן בדיוק? מזומן ← אישור בלי להקליד.

הסכום במזומן מעוגל ל-10 אגורות (כמו בכל חנות). כתוב "חסרים ₪…" — הלקוח לא נתן מספיק, אין קבלה.

4. תשלום באשראי

  1. מעבירים את הכרטיס במסוף האשראי כרגיל.
  2. אחרי שעבר — אשראי בקופה. הקבלה יוצאת.

הקופה רק רושמת שזה שולם באשראי. היא לא מחויבת לחיוב עצמו.

5. הנחה 🔒

  • ₪ על שורה: בוחרים שורה ← מקלידים סכום ← הנחה.
  • % על שורה: מקלידים אחוז ← % שורה.
  • על כל הקנייה: סכום ← ₪ סל, או אחוז ← % סל. אפס = ביטול ההנחה.
  • הקופה מבקשת קוד מנהל ← מקלידים ← אישור.

6. סגירת יום (Z) 🔒 — בסוף כל יום

  1. תפריט ← 2 ← קוד מנהל ← אישור.
  2. "סגירת יום?" ← אישור. יוצא דוח — שומרים אותו.

רוצים רק לראות כמה נכנס, בלי לסגור? תפריט ← 1 (דוח ביניים X).

7. ביטול עסקה שלמה

בטל ← בטל שוב לאישור. הביטול נרשם בדוח היום — זה בסדר.

אם כבר יצאה קבלה — זה לא ביטול, זו החזרה (בצד השני).

8. החזרה 🔒 — רק עם קבלה

  1. החזרה ← קוד מנהל ← אישור.
  2. מקלידים את מספר הקבלה שעל הקבלה של הלקוח ← אישור.
  3. סורקים רק את הפריטים שהוא מחזיר.
  4. מזומן או אשראי — לפי איך שמחזירים לו. קנה באשראי? מחזירים באשראי.

הקופה לא תחזיר פריט שלא נקנה בקבלה הזו, או יותר ממה שנקנה, ומחזירה במחיר ששולם בפועל (אחרי הנחות).

  2. C מוחק, ומקלידים 12 ספרות: יום חודש שנה שעה דקה.

  3. אישור.

אחרי הפסקת חשמל הקופה עשויה לבקש את זה לבד — אז חובה להקליד תאריך ושעה נכונים (גם אם מה שמוצג נכון). אי אפשר לכוון לתאריך שלפני הקבלה האחרונה.

11. הכרטיס ועדכונים

  • לא מוציאים את הכרטיס באמצע מכירה.
  • לעדכון מוצרים/מחירים: מוציאים ← מכניסים למחשב ← פותחים ניהול-הקופה.html או מעדכנים את מוצרים.csv באקסל ← שומרים ← מחזירים לקופה.
  • הקופה מראה מה השתנה במוצרים ← אישור לקבל, C לבטל.
  • הכנסתם כרטיס חדש/ריק? הקופה שואלת אם להמשיך בו ← אישור + קוד מנהל.
  • עדכון תוכנה מהספק 🔒: שמים את הקובץ בכרטיס ← הקופה שואלת "להתקין?" ← אישור + קוד מנהל (C = לא עכשיו). קובץ שלא מהספק — נדחה.
  • אחת לשלושה חודשים: מעתיקים את כל הכרטיס לתיקייה במחשב (גיבוי).

⚠️ כשמשהו לא בסדר

"אין כרטיס בקופה"מכניסים את הכרטיס עד הסוף.
"⛔ … פגום"מפסיקים ומתקשרים לספק. לא מוחקים ולא שומרים עליו כלום.
"⛔ הכרטיס נפסל"מפסיקים למכור ומתקשרים לספק. לא מוחקים ולא מתקנים כלום בכרטיס. כנראה שינו קובץ במחשב, או שזה כרטיס של קופה אחרת.
"⛔ השמירה לכרטיס נכשלה"המכירה לא נרשמה ולא יצאה קבלה. מוציאים, מכניסים שוב, ומנסים שוב. ממשיך? כרטיס מלא או פגום — לספק.
"צריך לסגור את היום הקודם"סגירת יום (סעיף 6), ואז ממשיכים.
"קוד מנהל שגוי" / "נעול עד…"מנסים שוב. אחרי 5 טעויות — נעול ל-5 דקות. לא זוכרים — לבעל העסק.
"מוצר לא נמצא"מוכרים כ"מחיר חופשי" (מחיר ← מחיר), ומבקשים מהבעלים להוסיף את המוצר.
"אזהרה: במלאי X בלבד"רק אזהרה — המכירה ממשיכה. לעדכן את הבעלים.
"… — בטוח?"הקלדתם מחיר מעל ₪5,000 או כמות מעל 50. נכון? אישור. טעות? C.
