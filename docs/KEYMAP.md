# מיפוי מקשים — PicoCalc ⇒ פעולות הקופה (25.10.2026)

מדבקות בעברית על מקשי ה-PicoCalc. הקוד במכשיר ממפה כל מקש פיזי לשם המקש במנוע (`engine/register.mjs` → `press(st, k)`).
התמונה: `docs/customer/img/keyboard.png` (הדמיה — מדבקות על תמונת היצרן).

| מקש פיזי | מדבקה | `k` במנוע | צבע |
|---|---|---|---|
| F1 | תפריט | `MENU` | תכלת |
| F2 | החזרה | `REFUND` | תכלת |
| F3 | הנחה | `DISC` | תכלת |
| F4 | % שורה | `PCT` | תכלת |
| F5 | % סל | `BPCT` | תכלת |
| Esc | בטל | `CANCEL` | ורוד |
| Tab | ₪ סל | `BASKET` | תכלת |
| CapsLK | × כמות | `QTY` | תכלת |
| Del | מחק | `DEL` | ורוד |
| ← Back | C | `C` | ורוד |
| ▲ / ▼ (חצים) | ללא שינוי | `UP` / `DOWN` | — |
| `~ | 00 | `00` | אפור |
| /? | . | `.` | אפור |
| 1–0 | 1–0 | `0`–`9` | אפור |
| Enter | אישור | `OK` | תכלת |
| Shift שמאלי | מחיר | `PRICE` | תכלת |

⚠️ לבדוק במכשיר: שה-STM32 של המקלדת מדווח Shift שמאלי/ימני ו-CapsLK כלחיצות נפרדות (ולא רק כמצב). אם לא — מעבירים את מחיר/אשראי/× כמות למקשים פנויים (למשל מקשי הסימנים הריקים) ומעדכנים מדבקות ומדריך.
